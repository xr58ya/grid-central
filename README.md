# Grid Central

Your personal race engineer for iRacing: a voice spotter and driver coach, live race strategy, lap data, setups,
a race overlay, a paint shop, a phone pit wall, a team hub and Discord for your league.

## Download

Get the latest **GridCentral-Setup** from [Releases](https://github.com/xr58ya/grid-central/releases/latest),
run it, and follow the steps. Grid Central checks this page for updates and offers to install them for you.

Windows may warn you that the Setup program isn't recognised (it isn't code-signed yet). Choose
**More info → Run anyway**.

## Lap library

The `lap-library` folder holds reference laps that everyone with Grid Central can load and coach against
(Lap data → Online · reference laps). To add one, tick the lap in Lap data and press **Prepare for the library**,
then upload the saved lap file and the new `index.json` to this folder (replacing the old `index.json`).
